# 공부하는 탱크 — 온라인 서버

뒤집힌 바다 서버와 같은 방식(GitHub + Render + Neon). 부품 없이 도는 웹소켓(`ws-lite.js`)과 저장소(`store.js`)는 뒤집힌 바다에서 그대로 가져왔다.

## 지금 되는 것 (1~3단계)
- 이름 + 내가 정한 비밀번호로 입장 (처음이면 바로 만들어짐). '관리자·선생님·운영자'가 들어간 이름은 못 씀
- 온라인 기록(골드·장비·계급)은 서버에 저장, 혼자 하기 기록과 완전히 따로
- 로비: 방 목록, 방 만들기, 로비 채팅(빠른 문구 + 자유 입력, 나쁜 말 가리기, 1초에 1개)
- 방: 2~8명, 개인전/팀전(4인 1팀까지), 맵·라운드·턴 시간·문제 데이터(방장), 준비, 팀 바꾸기, 빈자리 컴퓨터로 채우기, 내보내기, 방 채팅
- 반 코드: 선생님 화면(`/admin`)에서 만들고, 그 코드로 들어온 학생만 학급 모임방에서 함께
- 끊긴 사람: 60초 안에 돌아오면 원래 방으로
- 온라인 대전: 서버가 차례·바람·포탄·피해·보급 상자·컴퓨터 탱크를 계산하고, 휴대폰은 결과를 받아 보여 줌 (engine.js 공용 엔진, battle.js 대전 진행)
- 대전 중 연결이 끊기면 다시 들어왔을 때 그 화면으로 복구, 60초가 지나면 컴퓨터가 대신 움직임

## 만들고 올리기
1. `python3 build.py` → 혼자 하기 게임(`../공부하는탱크/index.html`)에 `client/online.js`를 붙여 `public/index.html` 생성
2. GitHub에 커밋·푸시 → Render가 자동 배포

## 로컬 시험
`ADMIN_KEY=시험용 DATA_DIR=data-t PORT=10000 node server.js` (DATABASE_URL이 없으면 파일 저장)

## Render 환경 변수 (선생님이 직접 입력, 채팅·코드에 적지 않음)
- `DATABASE_URL` — Neon 새 데이터베이스 접속 주소
- `ADMIN_KEY` — 선생님 화면(`/admin`) 열쇠
